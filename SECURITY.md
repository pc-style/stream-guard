# Security Policy

PII Guard is a beta privacy aid, not a guarantee that a screen is safe to share. Report security or privacy issues privately through this repository's **Security** tab by opening a private vulnerability report. Do not include real screen captures, personal data, custom phrases, or recordings in public issues.

Only the current `main` branch is supported before 1.0. There are no signed or notarized releases; the documented installer builds an immutable source commit locally and applies an ad-hoc signature.
